# Макет «Плавный переход»

![Концепт экрана iPod Video с выбранной длительностью 5 секунд](mockups/crossfade-wheel-settings.png)

Это визуальный макет, а не снимок работающей прошивки. Он фиксирует согласованный вариант экрана для iPod Video 5.5G:

- пункт Settings: «Плавный переход»;
- непрерывный горизонтальный ползунок с круглым бегунком и границами 3 и 10 секунд;
- сверху отображается выбранная длительность; значения меняются целыми секундами;
- поворот Click Wheel двигает бегунок по ползунку;
- нажатие центральной кнопки сохраняет выбор;
- MENU возвращает назад без изменения текущего значения.

При реализации нужно сохранить штатный вид RetailOS и использовать существующие механизмы локализации и хранения настроек. Для макета выбрано значение 5 секунд; это только начальное состояние изображения, а не окончательное значение по умолчанию.
