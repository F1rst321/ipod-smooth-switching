# Карта штатного Settings UI

Исследование относится к точному OSOS 25.1.3 из IPSW и неизменённой резервной
копии iPod Video 5.5G 30 GB. Оно только читает бинарные файлы. Изменённого UI
или готовой прошивки пока нет.

## Меню Settings

Resource inventory в OSOS находит общий блок ресурсов, начинающийся с
`OSOS+0x331da0`: в нём 40 `Menu`, 991 `Str`, 1064 записи `TCmd`, 158 `Type` и
619 `View` ресурсов. Меню Settings имеет ID `24598`, находится по
`OSOS+0x4af530`, содержит 18 строк и занимает 724 байта.

В русской таблице строк (`OSOS+0x30fcf4`) подписи меню закодированы UTF-8.
Проверенные метки включают «Конфигурация», «Главное меню», «Перемешивание»,
«Повторение», «Предел громкости», «Яркость», «Эквалайзер» и «Щелчки». Для
нового пункта потребуется добавить или безопасно переиспользовать запись
`Str`; изменить запись меню; и проверить поведение выбора и локализации.
Текущий ресурс имеет 18 записей, поэтому наличие места для дополнительной
строки нельзя предполагать без перестройки ресурсного блока и проверки его
границ.

## Калибровка на существующей настройке

У строки «Предел громкости» метка имеет ID `24656`; связанный View ID `17538`
находится по `OSOS+0x4cf8b0` и занимает 460 байт. В этом View пять элементов:
три `BMap`, один `None` и один `Str`; элемента `Cntl` там нет. В записи строки
также найдено значение свойства `0x6000604f`. Это подтверждает конкретный
штатный экран и связанное свойство, но не доказывает, что View является готовым
универсальным контролом 3–10 секунд.

Кандидат на дополнительный байт в сериализуемой области
`iPod_Control\\Device\\Preferences` находится по смещению `+0xb70`, однако
его getter/setter, ключ и доступ из UI не подтверждены. `Preferences+0xb70`
следует считать только поисковым кандидатом.

## Оставшиеся связи для реализации

- Проследить, как поле меню открывает View и где обрабатываются вращение и
  нажатие Click Wheel.
- Определить штатный класс регулятора, диапазон, координаты дорожки и бегунка.
- Подтвердить формат и lifecycle файла Preferences, затем выбрать отдельный
  ключ и проверить сохранение после перезагрузки.
- Выбрать способ добавить строку во все таблицы локализации и проверить
  ресурсные смещения, размеры и контрольные суммы OSOS.
- Добавить настоящий обработчик, который управляет работающим аудиопереходом;
  один только новый экран не реализует кроссфейд.

## Повторяемые команды

```powershell
py -X utf8 .\tools\ui_resource_probe.py `
  .\firmware\extracted\audio-analysis\osos.bin `
  --menu 24598 --menu-text --language-block 0x0030fcf4

py .\tools\ui_view_probe.py `
  .\firmware\extracted\audio-analysis\osos.bin --id 17538
```

`tools/ui_resource_probe.py` и `tools/ui_view_probe.py` открывают файл как
обычные read-only данные; к физическому iPod они не обращаются.
